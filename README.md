# Atlas — AI phone agent for Android

- **Files**: indexes all of shared storage (All files access), searches by name, folder and AI description; previews images, PDFs and videos; asks Gemini/Claude what an image or PDF contains; smart organise (by type or by topic), duplicates, Atlas Bin.
- **Errands**: an accessibility-service agent opens Uber, Ola, Rapido, Swiggy, Instamart, Zomato, Blinkit, Zepto, Gmail… and taps/types its way through. It always stops with Confirm / Cancel before booking, ordering, paying or sending, and never enters OTPs, PINs or passwords.
- **Email**: drafts in chat, rewrite, attach phone files, hands off to Gmail and (with the agent on) taps Send.
- **AI**: your own Gemini or Claude key, switchable in Settings.

Built by GitHub Actions on every push to `main`; the APK is attached to the newest release.
